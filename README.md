# SilansSubtitles

Программа для скачивания видео и субтитров с YouTube. Окно космическое: ссылка слева, очередь скачиваний справа.

Последняя сборка и форма обратной связи лежат на сайте: **https://voice-next-door.netlify.app**

SilansSubtitles обновляется вместе с сайтом. Когда программа меняется, те же правки попадают в этот репозиторий, а сборка на сайте соответствует этой версии. Сайт — место, где скачивать программу и писать, если что-то работает не так.

## Что умеет

- Скачивает видео в MP4, MKV и WEBM
- Скачивает субтитры в SRT, ASS, VTT, TTML и LRC
- Берёт обычные и автоматические дорожки, в первую очередь русские, украинские и английские
- Ставит несколько ссылок в очередь и даёт отменить загрузку
- Сохраняет файлы в выбранную папку
- Принимает ссылку вставкой или перетаскиванием

## Запуск

Нужен Python с `pythonw` и пакеты `yt-dlp`, `Pillow`. Для перетаскивания файлов нужен `tkinterdnd2`. Для части качеств видео нужен `ffmpeg` рядом с программой.

1. Откройте папку с `SilansSubtitles.pyw`.
2. Запустите `Silans Subtitles.bat` или `pythonw SilansSubtitles.pyw`.
3. Вставьте ссылку на ролик и нажмите «Скачать».

Готовую сборку можно взять на сайте: https://voice-next-door.netlify.app

## Состав репозитория

- `SilansSubtitles.pyw` — окно программы
- `Silans Subtitles.bat` — запуск через Python
- `assets` — фон, логотип и иконка

Локальные настройки, журнал и ключ Telegram в репозиторий не входят.
